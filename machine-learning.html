Learning properties. Designing measurements.

How can physical insight help machine learning infer electrolyte properties—and decide which experiment to perform next?

My current research at DGIST focuses on physics-based parameter identification and surrogate modeling of lithium-ion batteries.

I have developed a TabPFN model to infer the lithium-ion transference number (t₊), electrolyte diffusivity (Dₑ), and ionic conductivity (κ) from lithium symmetric-cell data. I am now integrating a physics-informed active learning step that uses noise-scaled parameter sensitivities and validation-error-based weights to select informative current waveforms for the model.

t₊ · Li⁺ transference numberDₑ · Electrolyte diffusivityκ · Ionic conductivity

Where physics enters

  • Data generation: transport equations and two-sided SEI growth determine the simulated response.
  • Features: voltage, initial and final impedance, and an observed EIS peak-frequency feature connect model inputs to physical behavior.
  • Experiment selection: noise-scaled sensitivities estimate the information added by a new current waveform, including coupling between parameters.

The adaptive loop

After fitting an initial learner, normalized validation errors define the property weights. Every remaining candidate is ranked with the same weights. The top candidate is then fitted and validated; it is accepted only when the actual validation criteria improve. Rejection stops the loop and preserves the previous model.

Current status: the TabPFN model has been developed, and the active learning integration is in progress. Its impact on parameter inference is still being evaluated.

What I want to learn next

When do local physical sensitivities predict useful gains in inference? How robust is waveform selection to the design points, numerical regularization, and model mismatch? What additional evidence is needed before transferring this workflow to experimental electrolytes?
