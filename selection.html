METHOD EXPLAINER / ADAPTIVE SELECTION

More weight on what is hard to infer.

The selection rule combines the learner’s current validation errors with the physical information expected from a new waveform.

1. Turn errors into weights

Twenty percent of the weight is shared equally between the three target properties. The remaining eighty percent follows their relative normalized mean-squared errors.

wⱼ = 0.2 / 3 + 0.8 eⱼ / (e₁ + e₂ + e₃)

2. Rank physical information gains

At representative material–temperature scenarios, finite differences produce a noise-scaled sensitivity matrix. Candidate information is added to the information already accumulated. A weighted reduction in the inverse-information diagonal defines the selection score.

F_candidate = Jᵀ R⁻¹ J
score = Σⱼ wⱼ ⟨[F_current⁻¹]ⱼⱼ
              − [(F_current + F_candidate)⁻¹]ⱼⱼ⟩

A small ridge regularizes inversion. Scores are averaged across scenarios; information matrices for different unknown materials are not pooled. The derived EIS peak feature is not counted again as an independent measurement.

3. Validate the nominated candidate

The best-ranked candidate is fitted once. It must improve the weighted validation error by at least max(10⁻⁶, 1% of the previous score), with each target satisfying new error ≤ 1.2 × old error + 10⁻⁴. Otherwise the algorithm retains the previous model and stops.

This local information proxy does not establish global identifiability or guarantee a better TabPFN prediction. Final test data are excluded from weighting, ranking, and acceptance.
